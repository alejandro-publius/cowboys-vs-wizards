# Reopen a captured boss’s reward duel

Kiro CLI connected the earned Wanted posters to the existing Fable-designed showcase duels. After earning a reward, open Wanted and choose **Duel with the Wraith Posse** or **Duel with the Dragon Posse** on its poster.

Codex opened Wanted in Chrome with a fresh profile, then with each boss separately cleared. The fresh board offered neither showcase. Each earned poster reopened only its own draft, on seed 2328 for Wraith and seed 468 for Dragon. Starting the showcase did not add a counted match.
