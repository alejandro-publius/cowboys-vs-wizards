# Decisive lane on the duel result

Kiro CLI implemented the result cause from clash damage events. Codex checked it in Chrome. The previous result named the round. The new result also names the lane and troop, so a player can see where their defense failed.

Build with `npm run build`. Open `dist/cowboys-vs-wizards-board-duel.html?seed=4` in a fresh browser profile, choose Play, then end every turn without summoning. Round 3 displays “Lane 2: Skeleton broke your Base.” The first-run Wanted notice and replay buttons still appear.
