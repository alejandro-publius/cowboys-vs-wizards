# Practice after a rival duel

Kiro CLI connected the loss and draw results for two unlocked Wizard rivals to Fable's existing practice positions. Stargazer opens the Dynamiter choice in round one. The Imp opens the tribute choice in round four. The links use the existing seven-win gate and practice records no wins or rewards.

In Chrome with seven wins in the local profile, Codex opened each rival from the title screen and passed to the result. The result opened Normal Wizard practice on seed 4 for Stargazer and seed 4671 for the Imp.
