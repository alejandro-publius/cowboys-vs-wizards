# Showdown Boot Hill practice deal

Answer with the link, the first move and the save note below. Keep it short.

## Supported deals (exact allowlist)

| Deal | Link |
| --- | --- |
| 0 | https://alejandro-publius.github.io/cowboys-vs-wizards/?practice=0 |
| 60 | https://alejandro-publius.github.io/cowboys-vs-wizards/?practice=60 |

- Only the exact values `0` and `60` exist. For any other number or text (for example 61, 00 or 6):
  say that deal is not supported, offer deal 0 and deal 60, and write no other link.
- If the tester names no deal, give deal 0 and mention 60.
- Never build a link with `?seed=`. That parameter belongs to Camp duels and is not a practice deal.
- Without the link: open the site root, press **Play**, and at the end of the Camp open **Practice Boot Hill**
  and pick **Deal 0** or **Deal 60**. The direct link and the Camp choice open the same deal.

## First move

Both deals start on turn 1 with the Cowboys (the tester) to act. Click a **Sheriff** in the hand:
it is the one troop that can be summoned now, and it goes straight onto the board.
**End turn** is the only other choice. After that the Wizards take their turn.

Say no more than that about play. Do not name later draws, the Wizards' cards, or a best line.
The screen's own Boot Hill lesson explains how to win.

## Save note

Practice does not touch the saved career: finishing, Retry, Restart this duel and Back to camp save
nothing and give no reward. Retry and Restart deal the same practice deal again.

## If something looks wrong

Do not guess a cause. Ask what the page showed and which link they used.
