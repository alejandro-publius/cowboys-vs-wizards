# Design: Round-one tempo
- Flag: a plain boolean `experimentalRoundOneBaseShield` on the match state. Only tests and `scripts/compare-round-one-tempo.mjs` set it, on an opening state. `applyAction` clones the whole state, so the flag lasts the match. `publicState` copies named fields only, so the flag never reaches the CPU or the page.
- Rule: `resolveClash` in `src/game/clash.js` sets the dealt amount to 0 when the flag is `true`, the round is 1 and the lane has no blocker. Traps, the attack snapshot, blockers, defeats and `resultAfterClash` are unchanged. A shielded event is `{ ...damage, amount: 0, before: n, after: n, shielded: true }`. With the flag off, the event object is built exactly as before, with the same keys in the same order.
- Harness: `scripts/compare-round-one-tempo.mjs` has the same structure as `scripts/compare-opening-policies.mjs`. For each seed and each first seat it builds the opening with `openingMatch` (`shipped` or `both`), sets the flag for the two shield policies and plays it with `playMatch` and `chooseAction` on both sides. Rows are paired by (seed, first seat). The output gives the per-policy summary, paired changes, the RT-10 `verdict`, a seed 0 / seed 60 section and one row per match.
- Checks inside the harness: card conservation after every action; every action listed by `legalActions` on the full state; `after = max(0, before − amount)` on every damage event; Base events summing to the orbs lost; a `shielded` key only in round 1 under the flag; shipped runs with the natural first seat equal to `playMatch`; a shield run with no shielded hit equal to its twin, action for action and in its final state.
- Receipts: `results.json` (with rows) and `summary.json` (printed output) per sample under `.artifacts/card-rd/round-one-tempo/`, plus the SHA-256 of the frozen files and of each run.
