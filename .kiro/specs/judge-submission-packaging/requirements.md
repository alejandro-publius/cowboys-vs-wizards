# Judge submission materials

1. From the README or the Devpost pitch, a first-time visitor can open a playable Saloon choice, see what a fifth bounty win earns, and find a recorded Kiro run.
2. Each of Devpost’s five [judging criteria](https://kiroween.devpost.com/rules) has an inspectable example. The packet keeps observed results, proposed form selections and pending human playtests distinct.
3. The Crew bonus description links to the separate Night Watch app and a dated scheduled report. Each run’s counts come from its own receipt.
4. Local links resolve in the staged checkout.
